banditshell

A desktop shell for Hyprland, written from scratch in Quickshell. Nothing sits on screen until you reach for it.

What's in it

  • The launcher. It answers as you type. Sums, units, dates and colours go through qalc, and it finds apps, open windows, emoji, your scripts, Wi-Fi networks and SSH hosts.
  • Questions in the launcher. Type ask and a question. Claude Code or Codex answers on the plan you already pay for, or Ollama on your own machine, with no API key to paste.
  • The island. A notification, a song change or a finished download takes the spot at the top of the screen, and the rest wait beside it.
  • The sidebar. The clock pulls out into a calendar. Quick controls, notifications, a clipboard history and a media card with word-timed lyrics are one pull or one key away.
  • Settings. A floating window that drives the whole machine: Wi-Fi, Bluetooth, monitors, sound, power and the night light.
  • The session menu. Shut down, restart, log out, lock and sleep sit on the right edge. On the lock screen the power buttons need a hold, so a stray click never ends your session.
  • Files. A file manager with a terminal pane. Copy and paste works with other apps, and a drive shows up the moment you plug it in.
  • Desktop widgets. The time, a month calendar, what is playing, processor and memory load and quick timers, on the side of the screen you pick.
  • Bare mode. One switch turns all of the chrome off.
  • Updates from the inside. The update menu fetches the new version, and a What's new card says what changed.

Install

On any distro

You need Hyprland and Quickshell. The installer brings them where your distro packages them, along with every tool the shell calls and tab completion for zsh and bash. It works with pacman, apt, dnf, zypper, xbps and apk, and asks for sudo only when a package needs installing. Arch is where the shell lives every day.

  1. git clone https://github.com/marcusbandit/banditshell.git
  2. cd banditshell
  3. ./install.sh
  4. bin/banditshell start

./install.sh --dry-run walks every step without installing anything. To start the shell with Hyprland, add one line to your config:

  1. exec-once = ~/.local/bin/banditshell start

On Omarchy

Keep Omarchy's own shell and add banditshell island to its bar: now playing, word-timed lyrics, timers and notifications.

  1. omarchy plugin add https://github.com/marcusbandit/banditshell-island.git --enable

The island shows notifications once Omarchy's own are off, with omarchy plugin disable omarchy.notifications and then omarchy restart shell. More on GitHub and in the Omarchy plugin marketplace.

Everything is a command

$ banditshell panel launcher toggle
$ banditshell wallpaper next
$ banditshell clock timer start 10m
$ banditshell screen border off
$ banditshell panel Tab
calculator  clipboard  close  files  hotkeys
island  keyboard  launcher  media  notifications
quickcontrols  session  settings  wallpaper
