What's in it

  • Settings for the whole machine Ten categories that grow out of the sidebar and drive the real thing: Wi-Fi, Bluetooth, monitors, sound, power and the night light.
  • Bare mode One switch turns all of the chrome off. A wallpaper picker sits next to it.
  • Streamer mode An OBS deck for when you are live.
  • A memory Restart the shell and the panels you had open come back, Settings on the page you left it.
  • Updates from the inside The update menu fetches the new version and a What's new card says what changed in plain words.

Install

On Omarchy

Add banditshell island to Omarchy's own bar instead of installing the full shell: you get now playing, word-timed lyrics, timers and notifications, and leave out the launcher, sidebar and Settings that come with a second shell.

  1. omarchy plugin add https://github.com/marcusbandit/banditshell-island.git --enable

Only one program can show notifications, so the island shows them once you turn Omarchy's off with omarchy plugin disable omarchy.notifications and omarchy restart shell. More on GitHub and the Omarchy plugin marketplace.

Everywhere else

You need Hyprland and Quickshell. The installer brings them where your distro packages them, along with the Monocraft font, every tool the shell calls and tab completion for zsh and bash. It uses whichever of pacman, apt, dnf, zypper, xbps or apk the machine has, and asks for sudo only when a package needs installing. Arch is where the shell lives every day.

  1. git clone https://github.com/marcusbandit/banditshell.git
  2. cd banditshell
  3. ./install.sh
  4. bin/banditshell start

./install.sh --dry-run walks every step without installing anything. The installer links the command into ~/.local/bin, so to bring the shell up with Hyprland, add one line to your config:

  1. exec-once = ~/.local/bin/banditshell start

Drive it from anywhere

Everything the shell does is a command. A keybind, a script and a terminal all drive it the same way, and Tab completes every word.

$ banditshell panel launcher toggle
$ banditshell wallpaper next
$ banditshell clock timer start 10m
$ banditshell screen border off
$ banditshell doctor
