# A list page can have a dropdown beside its filter

Status: resolved
PR: #819
GitHub: #812

Raycast's search bar accessory: a choice beside the filter field that the
plugin hears about, such as "All, Today, This week".

Use case: Voice's history page filters by app or by day.

Done when: a `list` page can carry `dropdown` with choices, the person can
change it from the keyboard and the pointer, and the plugin gets the value
in a message and can answer with a new page.
