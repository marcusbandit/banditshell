# Window layouts

Status: done

Row: Desktop › Windows › Layout `layout` (dwindle, master, scrolling, hy3, add
custom). The layout cards and their previews are in the panel.

## What to build

- Write `general:layout` through the shell's Hyprland include (behind
  `sourceEdits`).
- Detect the hyprscrolling and hy3 plugins (`hyprctl plugin list`) and only
  offer their layouts when loaded; say how to install them otherwise.
- Custom layouts: how they plug in is undecided. The card stays an entry point
  with its info tip and Add button.

## Built

The option writer every Hyprland ticket here rides on landed with this one.
`services/hyprland-lua.js` gained `planOption`: given the scanned files and an
option path (`general:layout`, `input:touchpad:tap-to-click`, or a device's
own key), it rewrites the value where `hl.config` or an `hl.device` block
already sets it, or adds the field to the nearest table that exists, or
appends one `hl.config` call to the main file. `HyprConfig.setOption` runs it
through the same commit / `--verify-config` / revert / reload chain as binds,
behind `sourceEdits`, and reports how it ended through `optionSettled`. A value
built by code, set under a condition or function, set in two places, or handed
over as a variable is refused with the file and line it comes from. Tests are
in `tests/hyprland-lua.test.js`; the real Hyprland accepted every shape on
copies of this machine's config.

There is no live `hyprctl keyword` after the write, on purpose: Hyprland 0.56's
Lua parser answers it with "keyword can't work with non-legacy parsers", and
the reload that closes the chain re-applies the file anyway.

The layout row writes `general:layout` and reads it back from
`hyprctl -j getoption`; `layout` left `planDefaults` and `isNew` is gone. A
live layout that is none of the four cards (this machine's `lua:stage`) shows
as the custom card, named in its row. Custom layouts stay undesigned: the card
is still an entry point with its info tip and Add button, `customLayout` is
still planned.

Plugins: hy3 is offered only when `hyprctl plugin list` shows it. Scrolling is
offered when the plugin is loaded or when Hyprland itself has the `scrolling:`
options, because 0.56 ships it built in (this machine runs it with no plugin
loaded); the ticket's premise that it is always a plugin is out of date. A
card that is not available is dimmed, and clicking it or hovering it says how
to get it (hyprpm).
